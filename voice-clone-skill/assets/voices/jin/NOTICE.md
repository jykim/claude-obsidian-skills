# Jin voice profile

This 7-second, 24 kHz mono reference sample and matching Korean transcript were supplied and authorized for publication by the repository owner.

Use the profile only for transparent voice-cloning experiments. Do not use it to deceive, impersonate the speaker, imply endorsement, commit fraud, or bypass consent and applicable law. Disclose generated audio as synthetic whenever the context could otherwise mislead listeners.

Install the profile by copying this `jin` directory to `$VOICE_CLONE_PROJECT/voices/jin/`. Only the normalized reference is published; the longer source recording and redundant raw working copy are intentionally excluded.
